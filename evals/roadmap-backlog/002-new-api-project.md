# Eval 002 — Proyecto nuevo sin interfaz

## User request

> Planificá una API de conciliación de pagos sin UI. Quiero contratos y un flujo de prueba antes de implementar.

## Context

- La API procesa información financiera sensible.
- No existe mockup ni corresponde crearlo.
- Se requiere considerar autenticación, autorización, inputs, secrets, auditoría, errores y operación.

## Expected behavior

- Activar modo creación.
- Usar F01 como validación equivalente mediante contratos, ejemplos y flujo de prueba.
- No forzar pantallas, layout o mockup.
- Planificar controles de seguridad a lo largo de definición, implementación y entrega.
- No convertir la planificación en autorización para implementar o instalar dependencias.

## Success criteria

La estructura común se conserva, la validación se adapta al tipo de producto y los riesgos sensibles son visibles sin inventar arquitectura definitiva.
