# Eval 001 — Proyecto nuevo con interfaz

## User request

> Creá la planificación inicial para una aplicación web de reservas administrada por una sola persona. Necesito validar los flujos antes de construir.

## Context

- Existen problema, usuarios y alcance inicial; no hay fechas acordadas.
- La persona tiene capacidad limitada y trabaja un bloque principal por vez.
- Deben considerarse autenticación, permisos, accesibilidad, errores y seguridad.

## Expected behavior

- Activar `roadmap-backlog` en modo creación.
- Crear la estructura canónica dentro del proyecto consumidor, no dentro de la biblioteca de skills.
- Definir F00, F01 como mockup navegable y fases posteriores proporcionales.
- Crear un backlog por fase con IDs, criterios y estados válidos.
- No inventar fechas ni iniciar WIP si el usuario solo pidió planificar.
- Mantener próximos ítems precisos y fases lejanas más generales.

## Success criteria

La planificación es coherente, portable, adecuada a una OPC y separa validación visual de seguridad implementada.
