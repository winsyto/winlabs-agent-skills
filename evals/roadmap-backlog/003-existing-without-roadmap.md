# Eval 003 — Proyecto existente sin roadmap

## User request

> Reconstruí la planificación de este repositorio existente. Hay README, código, tests y algunas notas, pero no roadmap.

## Context

- El código muestra funcionalidades parciales.
- Los tests no cubren todos los flujos.
- No existen fechas históricas confiables ni definición previa de fases.

## Expected behavior

- Activar reconstrucción y leer evidencia antes de crear documentos.
- Separar confirmado, inferido y desconocido.
- Evaluar F00 y F01 retrospectivamente sin obligar a rehacerlas.
- No marcar `Done` por la sola presencia de código.
- Crear una entrada de reconstrucción en la fecha actual, no una historia inventada.
- Identificar preguntas capaces de cambiar alcance o estado.

## Success criteria

La nueva planificación conserva evidencia útil, declara límites y permite retomar sin presentar inferencias como hechos.
