# Changelog

Los cambios relevantes de este proyecto se documentarán en este archivo. El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y las versiones seguirán [Semantic Versioning](https://semver.org/lang/es/).

## [Unreleased]

### Added

- Infraestructura documental y reglas de autoría de la biblioteca.
- Esqueletos iniciales de `product-analytics` y `dashboard-ux`.
- Directorios reservados para referencias y evals de ambas skills.
- Research comparativo y diseño conceptual previo al contrato operativo de `product-analytics`.
- Evals human-readable de `product-analytics` para casos positivos, negativos y routing ambiguo con `dashboard-ux`.
- Referencias operativas de `product-analytics` para jerarquías, definiciones, lifecycle e interpretación diagnóstica.
- Suite de `product-analytics` ampliada a ocho escenarios y reporte de evaluación conductual manual.
- Research comparativo, diseño conceptual y seis evals iniciales para `dashboard-ux`.
- Cuatro referencias operativas de `dashboard-ux` para modos y jerarquía, exploración y comparación, estados y feedback, accesibilidad y responsive behavior.
- Skill experimental `roadmap-backlog` para crear, reconstruir, migrar, consultar y mantener planificación persistente por proyecto.
- Plantillas Markdown portables, referencias bajo demanda y un validador opcional sin dependencias externas para `roadmap-backlog`.
- Diez escenarios de evaluación para continuidad, migración, interrupciones, avance, idempotencia y recuperación de contexto.

### Changed

- `product-analytics` promovida de Esqueleto a Experimental con un contrato operativo compacto y progressive disclosure.
- `dashboard-ux` promovida de Esqueleto a Experimental con Design mode y Review mode priorizado para auditorías concretas.
- Gate mínimo de promoción a Stable formalizado con evaluación conductual, revisión independiente, forward testing y uso real.
